# Foodnance logo files

Made 2026-10-03 from the approved gold chef-hat design. The shapes were traced from the
original image into vectors; the tagline ("Food meets profit") is real font outlines (Jost), so no
file here needs a font installed. Colours: gold gradient #7f5f24 to #e3c570, charcoal #262b2b, navy #0c4a6e.

| File | Use |
|---|---|
| `foodnance-logo.svg` / `.png` | Main logo, stacked, for light backgrounds (PNG is 2000 px, transparent) |
| `foodnance-logo-on-dark.svg` | Same, with a white FOOD, for dark backgrounds |
| `foodnance-logo-horizontal.svg` / `.png` | Icon beside the name, for site headers and email signatures |
| `foodnance-logo-horizontal-on-dark.svg` | Horizontal version for dark backgrounds |
| `foodnance-icon.svg` | The hat on its own (too detailed for sizes under about 48 px) |
| `favicon.svg`, `favicon.ico`, `favicon-16/32/48/192/512.png` | Browser-tab and app icons: simplified gold hat on a navy tile |
| `apple-touch-icon.svg` / `.png` | 180 px home-screen icon (square, the phone rounds it) |
| `og-image.png` | 1200 x 630 link-preview image for social sharing |

SVG files scale to any size without losing quality. The PNG and ICO files are fixed-size copies.
The favicon is a simplified drawing, not a trace, because the full hat is unreadable at 16 px.
